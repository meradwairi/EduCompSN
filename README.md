# EduCompSN

## Education and Social Networking Platform

EduCompSN is an education and social networking platform that connects **students, universities, and companies** in one environment.

The platform allows users to create profiles, share posts, interact with other users, communicate through chat, and manage education and career information.

## Features

- User registration and login
- User profiles
- Education and experience management
- Skills management
- Posts and comments
- Likes and interactions
- Search functionality
- University profiles
- Company profiles
- Real-time chat between users
- Notifications
- Document uploading
- Admin dashboard and user management

## Main Functionalities

### Authentication
Users can register, log in, and manage their accounts.

### Profiles
Users can create and update their profiles, education, experience, and skills.

### Social Networking
Users can create posts, add comments, like content, and interact with other users.

### Communication
The platform provides real-time communication between users using SignalR.

### Universities and Companies
Universities and companies can have profiles and interact with students through the platform.

### Documents
Users can upload and manage documents through their profiles.

### Administration
Administrators can manage users and platform content through the admin dashboard.
